# secure password generator

A lightweight, GUI-based password generator built with Python and Tkinter. It allows users to quickly generate strong, random passwords to improve digital safety.

## Motivation
This project was inspired by my community volunteer work conducting cybersecurity awareness workshops for seniors.

## Features
- **Graphical User Interface (GUI):** Clean and simple window interface using `tkinter`.
- **Customizable Length:** Choose the desired length for your password.
- **Strong Character Pool:** Combines uppercase letters, lowercase letters, digits, and punctuation symbols.

## How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Download or clone the `secure-password-generator.py` file.
3. Run the script using your terminal or IDE:
   ```bash
   secure-password-generator.py
